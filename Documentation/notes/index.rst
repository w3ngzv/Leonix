========
过程思考
========

过程思考是 Leonix 开发过程中设计思考的记录: 某个机制为什么这样做, 与更简单的
写法相比得失何在, 下一步打算做什么. 这些记录面向第一次接触内核开发的读者, 也
面向若干年后重新阅读本项目的作者. 目前各机制的精确约定(帧布局, 栈预算,
限制)也写在对应的篇目中; 这类约定增多之后, 再另立参考性质的文档.

第一篇说明芯片本身的设计思路, 其余各篇按代码的执行顺序排列, 后一篇以前一篇
的内容为前提.
